# 🖼️ Fit2flybot Telegram Photo Collage Bot

Fit2flybot (`@Fit2flybot`) is a production-ready, high-performance Telegram bot that enables users to combine multiple photos into customizable grid collages directly inside Telegram.

---

## 🔥 Features
* **Flexible Uploads**: Combine 2 to 9 photos per collage.
* **Supported Formats**: Full support for `JPG`, `PNG`, and `WEBP` formats.
* **Layout Grid Options**: Choose `Auto Grid`, `1x2`, `2x2`, `2x3`, or `3x3`.
* **Spacing Customization**: Adjust outer/inner grid padding (`0px`, `5px`, `10px`, `20px`).
* **Background Selection**: White, Black, Gray, or custom HEX input (e.g. `#FF5733`).
* **Image Fit Options**:
  * **Cover**: Crops image to completely fill grid cell bounds.
  * **Fit**: Keeps full photo aspect ratio with background padding.
* **Auto-Orientation**: Automatically handles EXIF rotation.
* **Privacy First**: Files are stored in temporary RAM buffers and wiped immediately after collage delivery.
